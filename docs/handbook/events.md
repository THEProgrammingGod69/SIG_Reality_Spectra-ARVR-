# Events

An event goes through three steps, and the **Events** page groups them for you:

1. **Upcoming** — announced on the public Events page, with a Register button
   when it has a registration link.
2. **Ended — not on the timeline yet** — it is over; it waits here until you
   put it on the timeline (one click).
3. **On the timeline** — shown in the Events timeline, its photos (if any) in
   the Gallery.

## Announce a new event

1. **Events** → **Add event**.
2. Fill in **Details**: Title, Category, How people attend, **Starts (India
   time)**, Ends (optional — leave empty for a one-day event), Venue, and a
   **Summary** of one or two sentences. The **Description** is optional; leave
   a blank line between paragraphs.
3. **Registration link (optional)**: paste the registration page's address
   (usually VIERP), starting with `https://`. Without one, the event shows no
   Register button.
4. **Poster** (optional): upload it, then check the description under it.
5. **Published** is ticked already, so the event appears on the site when you
   save. Untick it to keep a draft only admins can see.
6. **Create event**.

Open the public Events page and reload: the event is there, soonest first.

## After the event: the timeline

The event moves to **Ended — not on the timeline yet** by itself once it is
over.

- **Quickest:** press **Put on timeline** beside it. Done — it is on the
  public timeline at once.
- **With a recap and photos** (any time, before or after): open it, and under
  **After the event** write the **Recap** and upload **Photos** — many at once
  if you like (up to 60). Check each photo's description: it starts as "Photo
  from …"; make it say what is in the picture. Tick **On the timeline**, then
  **Save changes**.

Photos of timeline events also appear in the Gallery, under the event's
category.

## Add a past event directly

Use **Add event** as above, with dates in the past. **On the timeline** can be
ticked straight away, so the event goes onto the timeline in the same save.

## Change or delete an event

Open it, change anything, **Save changes**. **Delete event** (at the bottom)
removes it from the site with its poster and photos; it asks first. To take an
upcoming event off the site without deleting it, untick **Published**.

## If something will not save

The message beside a field says what it needs — for example, a title, a start
time, a venue and a summary are required, and only an event that has ended
can go on the timeline.
