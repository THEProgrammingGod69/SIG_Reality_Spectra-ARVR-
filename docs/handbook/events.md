# Events

An event goes through three steps, and the **Events** page groups them for you:

1. **Upcoming** — announced on the public Events page, with a Register button.
2. **Ended — needs a recap** — it is over; it waits here until you add photos.
3. **On the timeline** — shown in the Events timeline, its photos in the Gallery.

## Announce a new event

1. **Events** → **Add event**.
2. Fill in **Details**: Title, Category, How people attend, **Starts (India
   time)**, Ends (optional — leave empty for a one-day event), Venue, and a
   **Summary** of one or two sentences. The **Description** is optional; leave
   a blank line between paragraphs.
3. **Registration link**: paste the registration page's address (usually
   VIERP). It must start with `https://`.
4. **Poster** (optional): upload it, then check the description under it.
5. Tick **Published** when it should appear on the site. Leave it unticked to
   keep a draft only admins can see.
6. **Create event**.

Open the public Events page and reload: the event is there, soonest first.

## After the event: recap and photos

The event moves to **Ended — needs a recap** by itself once it is over.

1. Open it from the Events page.
2. Under **After the event**, write the **Recap**: what happened, in a few
   sentences.
3. **Photos**: upload them, many at once if you like (up to 60). Check each
   one's description — it starts as "Photo from …"; make it say what is in
   the picture.
4. Tick **On the timeline**, then **Save changes**.

The event now appears in the timeline, and its photos in the Gallery under the
event's category.

## Change or delete an event

Open it, change anything, **Save changes**. **Delete event** (at the bottom)
removes it from the site with its poster and photos; it asks first. To take an
upcoming event off the site without deleting it, untick **Published**.

## If something will not save

The message beside a field says what it needs — for example, a published event
needs a registration link, and only an ended event with at least one photo can
go on the timeline.
