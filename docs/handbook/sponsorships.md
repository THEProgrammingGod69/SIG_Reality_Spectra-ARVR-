# Sponsorship requests

Organisations ask about sponsorships and collaborations through the form on
the public Contact page. Requests arrive **only** in the admin panel — nobody
is emailed — so check **Sponsorships** regularly. The Dashboard shows how many
are new.

## Answer a request

1. **Sponsorships**: requests are listed newest first; new ones are open.
2. Read the message. Click their email address (or phone number) to reply
   from your own club email.
3. Set **Status** to _Contacted_ once you have replied, and _Closed_ when it
   is settled. The status saves as soon as you change it, so other admins can
   see who has been answered.

## Delete a request

**Delete** removes it for every admin; it asks first. Delete obvious spam —
the form already blocks most of it.

## Spam protection (for whoever looks after the website)

The form has a hidden trap field for bots, Cloudflare Turnstile, and a limit of
three requests per sender per hour. On the live site it is only offered when
Turnstile's keys are set; without them, the Contact page lists the club's
channels instead.
