# `src/components/admin`

Admin-panel components, built on shadcn/ui. shadcn/ui is used **here only** —
the public site uses the primitives in `src/components/ui`.

The admin event form's live preview must render the _same_ public components the
site renders, so preview and production can never drift.

Built in **Stage 6** (shell) and **Stage 7** (event editor).
