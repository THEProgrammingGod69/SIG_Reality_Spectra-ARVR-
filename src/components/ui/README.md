# `src/components/ui`

Design-system primitives: Button, Card, Badge, Container, Section, Heading, Text,
Input, Textarea, Select, Modal, Skeleton, EmptyState, Icon.

Rules:

- Token-driven only. No raw hex or px colour values.
- Keyboard accessible with a visible focus state.
- No data fetching and no business logic. These are presentational.

Built in **Stage 3**. `page-placeholder.tsx` is temporary Stage 1 scaffolding and
is deleted once every route has real content.
